# Python Projects

A collection of academic programming projects developed using Python, demonstrating skills in algorithm design, data processing, automation, and problem-solving.

## Projects

### 1. Fantasy Hockey Draft and Leaderboard

Developed a Python-based fantasy hockey simulation incorporating player drafting, roster management, and weekly performance tracking. Implemented functions to validate roster selections, enforce budget constraints, calculate player statistics, and generate leaderboards using positional weighting and performance metrics. Incorporated validation mechanisms to detect invalid selections and maintain fair competition.

**Skills:** Python, Functions, Conditional Logic, Data Structures, Input Validation, Algorithm Design

### 2. Matrix-Message Encryption and Decryption

Applied linear algebra and matrix operations to develop a mathematical message encryption and decryption system. Converted alphabetical characters into numerical representations, organized them into matrices, and applied encryption formulas to encode messages and recover their original contents. Demonstrated the practical application of mathematical principles to information security and cryptography.

**Skills:** Python, Matrix Operations, Linear Algebra, Mathematical Algorithms, Encryption and Decryption, Problem-Solving

### 3. Plane Ticket Validation and Flight Information

Developed a Python-based airline ticket validation system designed to process passenger information, verify ticket details, and manage flight-related information. Applied conditional statements, input validation, and logical operations to evaluate ticket information against predefined requirements and determine ticket validity.

**Skills:** Python, Conditional Statements, Input Validation, Data Processing, Logical Operations, Program Design

### 4. Social Media Data Analysis

Developed a Python-based data analysis project focused on examining social media information to identify trends, patterns, and meaningful insights. Applied programming techniques to process and interpret data, demonstrating how computational analysis can support data-driven decision-making and the evaluation of social media activity.

**Skills:** Python, Data Analysis, Data Processing, Pattern Recognition, Analytical Problem-Solving

### 5. Wackys Restaurant Ordering and Reservation System

Developed a Python-based restaurant management system incorporating speech-to-text ordering, table reservations, menu pricing, and promotional combo deals. Designed programming logic to process customer orders, manage reservation requests, and calculate order totals based on menu selections and available discounts. Demonstrated practical applications of programming and automation in a restaurant environment.

**Skills:** Python, Speech-to-Text Integration, Functions, Conditional Logic, Input Validation, Automation, Algorithm Design
